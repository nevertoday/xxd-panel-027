> 두꺼운 유백색 종이 · 얕은 요철 · 미세 음각선 · 무광 금빛 초점 · 박물관 질서

XXD Panel 027는 Codex와 호환 에이전트를 위한 이미지 생성 Skill입니다. 정체성, 실루엣, 자세와 서사 관계를 보존한 뒤 두꺼운 유백색 종이에 눌러 새긴 동양적 얕은 부조로 재구성합니다. 솟은 가장자리, 오목한 면, 미세한 음각선, 높이 차와 섬세한 그림자가 사진의 세부를 기계적으로 복제하지 않고도 식별성을 지킵니다.

원본 구조에 따라 부감, 정면, 약한 부감, 축선 확장 중 가장 적합한 시점을 고릅니다. 유백색·따뜻한 흰색·옅은 종이색과 넓은 여백이 중심이며, 결정적인 식별점 하나에만 아주 작은 무광 금빛을 허용합니다. 부드러운 온광이 종이 섬유와 압인 높이를 보여 주고, 글자는 축선·부조 아래·여백 가장자리·구조 윤곽에 맞춥니다.

## 왜 027이 필요한가요

일반적인 ‘부조 스타일’은 원클릭 3D 베벨, 흰 석고상, 고급 포장 압인, 과도한 금박으로 쉽게 무너져 원본이 범용 아이콘이 됩니다.

027은 순서를 뒤집습니다.

```text
정체성／실루엣／자세／관계 고정 → 원본에 근거한 시점과 축 선택 → 고유 부조 높이 지도 작성 → 얕은 양각·음각·선각·단차로 주제 요약 → 유백색 종이와 여백이 고요함 담당 → 금빛은 결정적 한 점에만 사용 → 읽히는 글자를 전시 구조에 정렬
```

무관한 사진으로 바꿔도 부조 실루엣, 높이 지도, 시점 축, 환경 윤곽, 금빛 초점과 문자 관계가 거의 그대로 성립한다면 027가 아닙니다.

## 027의 시각적 원칙

- **원본 정체성:** 최소 세 가지 고유 단서로 실루엣, 자세, 동작, 구조, 크기, 여백 형태와 관계를 보존합니다.
- **원본에 맞는 시점:** 부감, 정면, 약한 부감, 축선 확장 중 정체성과 공간 관계를 가장 잘 지키는 것을 고릅니다.
- **실제 얕은 부조:** 양각, 음각, 미세 선각, 종이 단차와 부드러운 가장자리 그림자가 두꺼운 종이의 물리적 범위에 머뭅니다.
- **박물관 질서:** 고요한 중앙축 또는 근거 있는 비대칭 축, 명확한 위계, 넓은 여백이 하나의 부조를 지지합니다.
- **동일 계열 종이:** 유백색, 따뜻한 흰색, 크림색, 옅은 종이색을 쓰고 높이와 조용한 그림자로 깊이를 만듭니다.
- **무광 금빛 초점:** 근거 있는 식별점 하나에만 극소량을 쓰며 넓은 금장식은 금지합니다.
- **실제 재질:** 부드러운 온광이 종이 섬유, 압인 가장자리, 오목면, 단차와 자연 그림자를 보여 줍니다.
- **전시 문자:** 극히 짧은 제목과 미세 문자를 축선, 부조 아래, 여백 가장자리, 구조 윤곽에 맞춥니다.

## 예시 · 곧 추가됩니다

저장소에는 향후 예시를 위한 [`assets/examples/`](assets/examples/) 폴더가 마련되어 있습니다. 프로젝트 작성자가 확인한 027 완성작만 추가하며, 그전에는 다른 스타일의 게시물이나 이미지를 자리표시자로 쓰지 않습니다.

향후 예시는 027의 적용 범위만 보여 줍니다. 예시의 주제, 은유, 팔레트, 문구, 화면 비율은 생성 참조나 기본값이 되지 않습니다.

## 네 가지 출력, 하나의 압인 부조 논리

네 가지 모드는 하나만 또는 여러 개를 함께 선택할 수 있습니다. `1`, `1+3`, `1、2、4`, `전체`라고 답하면 Skill이 중복을 제거하고 1→4 순서로 실행합니다. 각 모드는 별도 작업 폴더에 독립적으로 출력되며 한 장의 모음 이미지로 합치지 않습니다. `전체`는 원본 한 장당 PNG 7개(일반 모드 각 1개＋배경화면 4개)를 만듭니다. 크기는 모드별로 표시해 같은 답변에서 지정할 수 있고, 지정하지 않은 일반 모드는 원본에 맞춥니다. 문구는 기본적으로 선택한 모드가 공유하며 모드별 지정도 가능합니다.

| 모드 | 크기 규칙 | 결과물 |
| --- | --- | --- |
| `top-bottom` | 원본 적응형 | 위에는 전체 원본, 아래에는 027 동양 종이 압인 부조. 두 패널이 원본 크기를 유지하며 정확히 50/50 |
| `left-right` | 원본 적응형 | 왼쪽에는 전체 원본, 오른쪽에는 027 동양 종이 압인 부조. 두 패널이 원본 크기를 유지하며 정확히 50/50 |
| `design-only` | 원본 적응형 | 원본 사진은 보이지 않고 변환 디자인만 표시. 원본 비율과 크기 유지 |
| `wallpaper-pack` | 기기별 네 가지 크기 | 휴대전화, iPad, 데스크톱, 어린이용 스마트워치 PNG 개별 출력 |

정확한 사용자 픽셀 > 지정 비율 또는 용도 > 일반 모드의 원본 적응형 순서입니다. 원본 `027.md`의 3:4는 초기 창작 캔버스일 뿐 현재 Skill의 숨은 기본값이 아닙니다.

짝을 이루는 모드의 사진은 절제된 색 보정과 필요한 환경 확장만 적용해 사실성을 지킵니다. 디자인 단독과 배경화면은 사진을 근거로 사용하지만 원본을 보여 주지 않습니다.

### 배경화면 세트: 연결형 또는 독립형

배경화면에는 숨은 기본 크기가 없습니다. 일반 프리셋은 휴대전화 `1440×3200`, iPad `2048×2732`, 데스크톱 `3840×2160`, 스마트워치 `1024×1024`이며 기기별 사용자 지정 크기도 가능합니다.

- **연결형 세트(권장):** 먼저 iPad 기준 작품을 생성하고 승인합니다. 나머지 세 기기는 원본 사진＋동일한 기준 작품을 참조해 각 화면에 맞게 새로 구성합니다.
- **독립형 네 작품:** 각 기기는 원본 사진만 참조하며 시점, 부조 크기, 축선, 압인 높이, 금빛 초점과 문자 관계를 탐색합니다.

연결형은 크롭이 아닙니다. 네 장 모두 따로 생성하고 구성하며 검수하고, iPad→휴대전화→데스크톱→스마트워치 순으로 참조를 이어 붙이지 않습니다.

## 문구는 부조의 전시 질서를 공유합니다

생성 전에 자동 문구, 사용자 지정 문구, 무문자 출력 중 하나를 선택합니다. 문구가 있으면 대상 언어나 지역도 지정합니다.

자동 문구는 근거 있는 정체성, 장소성, 테마, 동작, 관계, 상징에서 극히 짧은 제목을 만듭니다. 정말 깊이를 더할 때만 키워드·번호·미세 주석을 0–3개 추가합니다. 철학적 문장은 원본이 명확히 뒷받침할 때만 쓰며 흔한 격려 문구로 만들지 않습니다.

장소, 날짜, 출처와 사실 번호는 사용자 제공이나 신뢰할 수 있는 근거가 필요하며 꾸며 내지 않습니다. 대상 문자 체계에 자연스러운 고급 편집용 명조／세리프 계열을 짙은 회색, 얕은 눌림, 극소량 무광 금빛으로 쓰고 중앙／원본 축, 부조 아래, 여백 가장자리, 구조 윤곽에 정렬합니다.

사용자가 완성 문구를 주면 그대로 유지합니다. 방향이나 수정 가능한 초안일 때만 대상 독자, 목적, 필수 단어, 어조, 함의를 보존하며 다듬습니다.

언어는 명령문의 언어가 아니라 의도한 독자를 따릅니다.

```text
목표 시장 또는 독자 > 지정한 결과물 언어 > 방향 지시 언어; 모두 불분명하면 생성 전에 질문
```

일본판은 자연스러운 현대 일본어를, 한국 독자용은 자연스러운 현대 한국어와 정확한 띄어쓰기를, 영국판은 영국 영어를 사용합니다. 아랍어판은 기본적으로 자연스러운 현대 표준 아랍어와 올바른 오른쪽에서 왼쪽으로 흐르는 구성을 사용합니다. 외모, 옷, 풍경, 간판으로 국적을 추측하지 않으며 가짜 외국어 문자를 쓰지 않습니다.

## 정확한 기하는 코드가, 작품은 이미지 생성이 맡습니다

이미지 모델이 원본에 묶인 부조 주제, 양각·음각, 선각, 단차, 유백색 종이, 금빛 초점, 촉각적 빛과 전시 문자를 만듭니다. `scripts/compose_panel.py`는 캔버스 계획, 정확한 50/50 래스터 합성, 최종 크기와 검수만 수행하며 프로그램 그림으로 결과물을 위조하지 않습니다.

```bash
python3 scripts/compose_panel.py --plan --layout top-bottom --source photo.png
python3 scripts/compose_panel.py --plan --layout left-right --size 2560x1440
python3 scripts/compose_panel.py --audit result.png --layout design-only --size 2048x2048
```

정확한 상하 캔버스는 전체 높이, 좌우 캔버스는 전체 너비가 짝수여야 합니다. 요청 픽셀을 몰래 변경하지 않습니다.

## 경계와 신뢰

- 각 사진은 독립된 작업 안에서만 사용하며 다른 입력, 과거 결과, 예시의 피사체, 색, 문구, 구도를 빌리지 않습니다.
- 호출할 때마다 새 작업 폴더를 만들고 원본과 조건이 같아도 새로 생성합니다.
- 결과물은 PNG 비트맵이며 SVG, HTML, Canvas, 프로그램 드로잉 대체물이 아닙니다.
- 설정된 비트맵 브리지는 정제된 상태만 출력하며 공급자, 엔드포인트, 헤더, 인증 정보, 프롬프트, 응답 본문을 노출하지 않습니다.
- 선택한 일반 모드마다 파일 1개를 반환하고, `wallpaper-pack`을 선택하면 독립 배경화면 4개를 추가합니다. `전체`는 원본 한 장당 PNG 7개를 네 개의 동급 모드 폴더에 저장하며 모음 이미지로 합치지 않습니다.

로컬 합성에는 Python 3와 Pillow가 필요합니다. 안전한 비트맵 브리지는 Python 3.11 이상의 `tomllib`을 사용합니다. 이미지 생성에는 내장 래스터 기능이 있는 호스트 에이전트 또는 이미 설정된 호환 경로가 필요합니다.
