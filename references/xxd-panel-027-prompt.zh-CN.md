# XXD Panel 027｜东方纸张压印浮雕生产提示词

只处理当前任务明确提供的这一张源照片。先锁定主体或不可拆分关系、轮廓、姿态、动作、关键开口、功能结构、尺度、负形、方向与距离，至少保留三个源图专属识别线索。不要借用旧成品、样张或其他输入的主体、浮雕结构、金色焦点、文字和构图。

## 源图专属浮雕图谱

把主体重构为压印在厚重乳白、暖白或浅纸色纸张上的浅浮雕，而不是机械复制照片细节。逐项决定：哪个轮廓成为凸起边缘，哪个体量成为低浅平面，哪个开口成为凹陷，哪个遮挡成为高度阶差，哪个小结构成为细线刻，哪个关系成为共享浮雕边界。

人物保留姿态、朝向、衣着体块与关系距离；动物保留身体节奏和头部方向；植物保留生长走势；建筑保留天际线、轴线和关键开口；器物与交通工具保留功能轮廓和负形；景观保留源图专属地形、地平线或纵深关系。

从主体自身结构选择俯瞰、正视、微俯视或轴线延展，不给所有对象套同一视角。以少量宽阔的压印高低差建立主体，再用必要的细线刻、边缘投影和同色明暗补足识别。浮雕高度必须符合厚棉纸或手工纸的物理尺度，不做深雕、石雕、石膏像或微缩场景。

## 博物馆展陈秩序

读取主体的视觉重心、轮廓走势、纵深顺序、对称性、动作与功能轴线。使用宁静的中央轴线或源图有依据的偏轴，建立清晰主次和一个视觉中心。环境轮廓仅在有助识别、尺度或纵深时少量保留，不能扩张成复杂布景。

大面积乳白、暖白、奶油白或浅纸色留白承担宁静与展陈距离。不同设备与画幅必须重新安排浮雕尺度、轴线、层次、文字与安全区，不得机械居中或裁切另一张成果。

## 同色纸面、柔光与哑金焦点

画面和主体保持同一浅纸色系，层次来自浮雕高低差、边缘软影、细微综合色温与极小明度差，而不是多彩配色。使用柔和、偏暖、漫射光揭示纸纤维、压印边缘、凹槽、阶差与自然投影，同时保持整体近乎单色。

只有当源图存在一个决定身份或叙事的关键局部时，才可在该处加入极少量哑金线、箔感细节或柔和暖白光。金色必须克制、非镜面、非装饰，不得大面积铺金或制造第二焦点。

禁止渐变滤镜、泥灰做旧、灰色水泥、石膏、瓷器、塑料、亮膜、金属反射、深黑硬影、夸张倒角、低多边形、通用 3D 位移和廉价包装质感。

## 展览文字

服从已锁定的自动文案、用户准确文案或无文字模式，以及目标语言／地区。用户准确文案逐字保留；无文字时不生成任何字母、字符、数字、金色字或伪文字。

自动文案从主体身份、地点属性、主题气质、动作状态、关系或有依据的象征意义中提炼一个极短标题；只有真正深化画面时，才增加零至三个关键词、编号或微型注释。地点、日期、出处和事实编号必须由用户提供或可靠确认，不得虚构。哲理短句只有在源图能明确支撑时使用，必须带来会心一击，不能成为泛泛鸡汤。

文字使用目标文字系统中自然、克制、高级的衬线或编辑字体等价物，以深灰或极少量哑金呈现，可轻印刷、浅凹印。沿中央／源图轴线、主体下方、留白边缘或一个结构轮廓对齐，使文字与浮雕共同形成博物馆秩序；禁止后贴广告标题、伪古典标签、厚重立体字和伪外语。

## 模式与验收

严格服从附加的 `OUTPUT MODE`、`FINAL SIZE` 与 `DESIGN FRAME`。双联模式只生成设计半幅；纯设计与壁纸不显示原照片。每张壁纸按设备重新构图，不裁切其他设备成果，不绘制系统 UI 或设备模型。连贯壁纸共同参考原照片与同一张已批准定调图，绝不串联衍生图。

硬性验收：至少三个源图线索与主要动作或关系；一个主浮雕和克制环境轮廓；视角由源图结构决定；浅凸、浅凹、线刻、阶差和边缘软影物理可信；乳白／暖白纸面和大留白；最多一个极小哑金焦点；柔和暖光清楚表现纸纤维和浮雕高度；文字准确、可读并与轴线或轮廓对齐；无折纸、多彩纸艺、石膏、瓷器、深雕、微缩布景、浮夸镀金、廉价 3D 倒角、包装模板、照片残片或伪文字。

若任一硬性条件失败，纠正生成资产，不要用程序绘图、SVG、HTML、Canvas、位移贴图或后期文字覆盖伪造成品。
